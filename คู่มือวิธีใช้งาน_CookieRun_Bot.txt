CookieRun Classic Bot - คู่มือการติดตั้งและใช้งาน (ฉบับสมบูรณ์)
========================================================================

3 ขั้นตอนง่ายๆ สำหรับการเปิดใช้งานครั้งแรก:

------------------------------------------------------------------------
ขั้นตอนที่ 1: ติดตั้ง Python (ถ้ายังไม่มีในเครื่อง)
------------------------------------------------------------------------
1. ดาวน์โหลด Python 3.10 หรือใหม่กว่าได้ที่: https://www.python.org/downloads/
2. ตอนกดติดตั้งในหน้าแรก **สำคัญมาก**:
   >>> ติ๊กถูกที่ช่อง [x] Add Python.exe to PATH ด้านล่างสุดเสมอ <<<
3. ดับเบิลคลิกไฟล์ "INSTALL.bat" ในโฟลเดอร์นี้เพื่อติดตั้ง Library ที่จำเป็นทั้งหมดอัตโนมัติ

------------------------------------------------------------------------
ขั้นตอนที่ 2: ตั้งค่าหน้าจอโปรแกรมจำลอง (Emulator)
------------------------------------------------------------------------
บอทตรวจจับรูปภาพปุ่มและไอเทมที่ความละเอียดมาตรฐาน:
1. เปิดโปรแกรมจำลอง Android (MuMu, LDPlayer, Nox, หรือ BlueStacks)
2. เข้าไปที่ การตั้งค่า (Settings) -> หน้าจอ (Display):
   - ความละเอียด (Resolution): 1280 x 720 (แนวนอน / 16:9 / Landscape)
   - DPI: 240 (หรือค่ามาตรฐาน)
3. เปิดใช้งานการเชื่อมต่อ ADB / USB Debugging / Root ใน Emulator

------------------------------------------------------------------------
ขั้นตอนที่ 3: เปิดใช้งานบอท (เลือกได้ 2 วิธี)
------------------------------------------------------------------------
วิธีที่ A (แนะนำ): ดับเบิลคลิกไฟล์ "START_GUI.bat"
   - หน้าต่างตัวเปิดบอท (Desktop GUI Launcher) สไตล์เบเกอรี่จะเปิดขึ้นมา
   - ระบบจะสแกนและค้นหาจอ Emulator ที่เปิดอยู่ในเครื่องให้อัตโนมัติใน 1 วินาที
   - กดเลือกจอแล้วเข้าสู่ระบบเพื่อเปิดหน้าจอควบคุม Web Dashboard ทันที

วิธีที่ B: ดับเบิลคลิกไฟล์ "START_BOT.bat"
   - เหมาะสำหรับการรันบอทแบบ Terminal โดยตรง
   - หน้าจอ Web Dashboard จะเปิดขึ้นมาบนเบราว์เซอร์อัตโนมัติ (http://127.0.0.1:8000)

4. ตรวจสอบพอร์ต ADB ของโปรแกรมจำลองที่คุณใช้ (กรณีเชื่อมต่อด้วยตนเอง):
   - MuMu Player 12 : 7555 (หรือ 16384)
   - LDPlayer 9     : 5555
   - Nox Player     : 62001
   - BlueStacks 5   : 5555
5. กดปุ่ม "▶ เริ่มทำงานบอท" เพื่อปล่อยฟาร์มอัตโนมัติได้ทันที!

ฟังก์ชันพิเศษ:
- แจ้งเตือนผ่าน Discord: กดปุ่ม "🔔 Discord" บนแถบเมนูด้านบน หรือในแผงควบคุม แล้วใส่ Webhook URL เพื่อรับการแจ้งเตือนรอบการวิ่งและกล่องปริศนา
- ดูผ่านมือถือ: สามารถเปิดดูจอสตรีมและสั่งงานผ่านเบราว์เซอร์มือถือที่ต่อ Wi-Fi เดียวกันได้
- ตรวจจับกล่องปริศนา: บอทจะนับและสรุปกล่องปริศนา (ไม้/เงิน/ทอง/รุ้ง) เข้า Discord ให้อัตโนมัติ
- AI Auto Jump & Slide (60 FPS Fast Touch): สตรีมหน้าจอความเร็วสูง 60 FPS และสัมผัสความไวสูง (< 20ms) กระโดดหลบสิ่งกีดขวาง สไลด์ และเก็บเยลลี่เหรียญทองอัตโนมัติ
- ตัวติดตั้งสำเร็จรูป (Setup Installer): สามารถรัน "BUILD_INSTALLER.bat" เพื่อสร้างไฟล์ติดตั้ง CookieRunBot_Setup.exe ไปติดตั้งบนเครื่องอื่นได้โดยไม่ต้องลง Python!
